# Muebles Perdigón · Demo estática

Versión compilada para pruebas con datos ficticios. No contiene autenticación ni sincronización; los cambios se guardan solo en cada navegador. No introducir datos reales.

Subir TODOS los archivos de esta carpeta a la raíz de un repositorio GitHub. No subir el ZIP sin descomprimir.

Netlify: importar el repositorio; directorio base vacío, comando de compilación vacío y directorio de publicación punto (.).

Vercel: importar como Other, comando de compilación desactivado y directorio de salida punto (.).

Sin variables de entorno ni Supabase. Las actualizaciones de código requieren recompilar y sustituir los archivos de esta versión estática. La URL final solo existirá cuando el proveedor confirme el despliegue.
